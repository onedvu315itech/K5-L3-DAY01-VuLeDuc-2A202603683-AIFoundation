## 3. Dự đoán và thực tế

*Chọn 3 dự đoán `predict(...)` lệch nhiều nhất so với kết quả. Mỗi cái: bạn đoán gì, ra gì, vì sao lệch.*
1. `ml_f1`:
  Expectation: F1 ~ 0.44, precision is higher than recall (0.67 > 0.33)
  Result: precision is actually the same as recall (0.0)
  Reason: FP < FN
2. `ml_lr`: 
  Expectation: if lr = 0.001 then loss goes down slowly, while with lr = 50, the loss increases significantly
  Result: the loss stays remain the same when changing lr = 0.001, but it decreases a half when lr = 50
  Reason: It seems like the loss is not almost affected by lr
3. `llm_fewshot`: 
  Expectation: F1 will increase based on data labels were defined. The cost will increase approximately 4x due to 4 examples
  Result: The cost is lower than I expect 
  Reason: The base is already big, so adding 4 short examples multiplies it by less
